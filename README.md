Recaps Switcher – изменения
===========================
Легендарный переключатель раскладок для Windows по клавише CapsLock.
Исходная программа несколько устаревшая, периодически зависает/крашится на Windows 10 x64.
Автор был уведомлён и получил ссылку на этот репозиторий с багфиксами.

Этот форк содержит доработки относительно [оригинальной программы](https://recaps.sourceforge.io/index_ru.html):

1. **Синхронизация доступа к спискам раскладок и хоткеев.**  
   Добавлен `CRITICAL_SECTION` и RAII-guard `LayoutsGuard`, что устраняет гонки между низкоуровневым хуком и обработкой уведомлений о смене раскладок.

2. **Поток ремапинга хоткеев.**  
   Вместо `SuspendThread/ResumeThread` используется `_beginthreadex` + событие для пробуждения, добавлено корректное завершение и освобождение ресурсов при выходе приложения.

3. **Конвертация текста и работа с буфером обмена.**  
   Функция `ConvertSelectedTextInActiveWindow` теперь:
   - использует таймауты `SendMessageTimeout`;
   - имеет ретраи для `OpenClipboard`;
   - безопасно обрабатывает пустой/занятый буфер обмена и не падает при отсутствии данных;
   - корректно восстанавливает буфер только при успешном сохранении.

4. **Сборка на x64.**  
   Исправлены касты HKL/HINSTANCE → `int`, добавлены helper’ы для безопасного сохранения/загрузки HKL из реестра, устранены критичные предупреждения компилятора (отсутствующие `return`, узкие преобразования).

5. **Вспомогательные улучшения.**  
   Добавлены проверки ввода в функциях буфера обмена, зануление структур, освобождение памяти только при успешном выделении.

6. **Стабильность низкоуровневого хука.**  
   Вся медленная работа (обновление значка в трее, запись в реестр, извлечение CD, инъекция клавиш) вынесена из обработчика `WH_KEYBOARD_LL` в цикл сообщений. Windows 10/11 снимает хуки, которые не успевают вернуться за `LowLevelHooksTimeout`, из-за чего CapsLock переставал переключать раскладку.

7. **Локализация интерфейса.**  
   Добавлены английский и русский языки. Язык по умолчанию берётся из настроек Windows (русская система → русский интерфейс), переключить можно в меню трея: **Язык / Language**. Справка (`Help`) также открывается на выбранном языке. Все строки собраны в `STRINGTABLE`, шаблоны диалогов — в `lang_ru.rc2`; новый язык добавляется по аналогии.

8. **CI и релизы.**  
   GitHub Actions (`.github/workflows/release.yml`) собирает **x64, Win32 и ARM64** на каждый push/PR и прикрепляет zip-архивы к GitHub Release при пуше тега `v*`. ARM64-сборка — нативная для Windows on ARM (не через эмуляцию x64).

### Что осталось без изменений
- Набор действий, горячих клавиш и логика настроек совпадают с оригиналом.
- Старые проектные файлы (2003/2005/2008) не обновлялись; актуальная сборка — `recaps.2010.vcxproj`.
- MFC больше не требуется: `resource.rc` использует `winres.h` из Windows SDK.

Подробнее о сборке см. `runbook.md`.
